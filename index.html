TurboTV — Cydia Repo

Repo Cydia chính thức của TurboTV — app xem YouTube 1080p cho iPad mini 1 (iOS 6 / iOS 9, chip A5) và iPad mini 2 (iOS 12).

Phiên bản hiện có: TurboTV 1.15.2 (com.bun.tubepro) — sửa crash khi tua (bỏ qua SIGPIPE), 4 theme glass, lịch sử xem, lấy stream bằng VISIONOS 1.02.

Thêm repo vào Cydia

Thêm vào Cydia

Hoặc thêm tay:

  1. Mở Cydia → tab Sources → Edit → Add.
  2. Dán URL này rồi bấm Add Source:
    https://twosix11D.github.io/TurboAsi4n/
  3. Chờ Cydia tải xong, vào repo TurboTV → cài TurboTV 1.15.2.

Tải trực tiếp file .deb

com.bun.tubepro_1.15.2_iphoneos-arm.deb (835.984 byte, MD5 1eef027e7f0baf984ca841ecbf6f61ba)

Chép file .deb sang iPad rồi mở bằng Filza → Cài đặt → Respring.
