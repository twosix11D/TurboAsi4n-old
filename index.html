TurboTV — Repo

Repo chính thức của TurboTV — app xem YouTube 1080p cho iPad mini 1 (iOS 6 / iOS 9, chip A5) và iPad mini 2 (iOS 12). Dùng được với Cydia, Sileo và Zebra (cùng 1 URL source).

Phiên bản hiện có: TurboTV 1.17.3 (com.bun.tubepro) — sửa lỗi LOGIN_REQUIRED ngẫu nhiên (tự seed lại visitorData rồi thử lại), log chẩn đoán đăng nhập từng bước, sửa phát nền im ngay khi bấm Home. Giữ nguyên 1.17.2 (Back thu nhỏ mini player, lặp lại video, bấm Home tự vào PiP, sửa kẹt phát nền, sửa log ghi version) + donate PayPal thật (paypal.me/turboasi4n) + mã VietQR của 1.17.1 và mọi tính năng 1.17.

Nhập đúng URL này (có dấu / cuối, KHÔNG phải link github.com):

Thêm repo vào Cydia

Thêm vào Cydia

Hoặc thêm tay:

  1. Mở Cydia → tab Sources → Edit → Add.
  2. Dán URL này rồi bấm Add Source:
    https://twosix11D.github.io/TurboAsi4n/
  3. Chờ Cydia tải xong, vào repo TurboTV → cài TurboTV 1.17.3.

Thêm repo vào Sileo

Thêm vào Sileo

Hoặc thêm tay:

  1. Mở Sileo → tab Sources → bấm dấu + (góc trên).
  2. Dán URL này rồi bấm Add Source:
    https://twosix11D.github.io/TurboAsi4n/
  3. Chờ Sileo Refresh xong, tìm TurboTV → cài bản 1.17.3.

Lưu ý: Sileo tìm file Release theo đường chuẩn dists/stable/Release — repo này đã có đủ bố cục chuẩn (dists/ + Packages.xz) từ bản 1.17.2. Nếu Sileo báo lỗi, chụp màn hình lỗi gửi nhà phát triển.

Thêm vào Zebra

Hoặc thêm tay:

  2. Dán URL này rồi bấm Add:
    https://twosix11D.github.io/TurboAsi4n/
  3. Chờ Zebra tải xong, tìm TurboTV → cài bản 1.17.3.
